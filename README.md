## Featured work

### [Real-World CCTV Anomaly Detection](https://github.com/asif3252/real-world-cctv-anomaly-detection)

A Python prototype for adding local video analytics to existing CCTV/NVR infrastructure.

- YOLO11n person detection and ByteTrack tracking.
- User-defined restricted areas, intrusion rules and configurable loitering thresholds.
- Local snapshots and timestamped CSV event evidence.
- Windows setup launcher, rule tests and a documented live-validation plan.

**Stage:** single-camera prototype. Live-camera accuracy and multi-camera performance remain to be measured.
